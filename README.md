# MSC Scalper (XAUUSD)

A Pine Script v1 indicator for Gold (XAUUSD) scalping on TradingView, featuring automated Support & Resistance with Flip Zones and a real-time performance dashboard.

---

### Quick Specifications

* **Asset**: XAUUSD (Gold)
* **Timeframe**: M1 / M5
* **TP1**: 500 pts ($5.00)
* **TP2**: 1,000 pts ($10.00)
* **Entry 2 (Add-on)**: 500 pts from E1
* **SL**: 1,000 pts ($10.00)

---

### How to Install

1. Open **TradingView** and navigate to your XAUUSD chart.
2. Click **Pine Editor** at the bottom.
3. Paste the code from `MSC_XAUUSD_Scalper.pine` and click **Add to chart**.

---

### Alerts Setup

1. Click **Create Alert** on TradingView.
2. Under **Condition**, choose `MSC - XAUUSD Scalper`.
3. Select **Any alert() function call** and save.
